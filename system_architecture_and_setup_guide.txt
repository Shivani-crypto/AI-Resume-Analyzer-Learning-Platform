1. EXECUTIVE SUMMARY & PLATFORM OBJECTIVES
--------------------------------------------------------------------------------
The AI Resume Analyzer & Micro-Learning Platform is an enterprise-ready web 
application that bridges automated resume parsing, AI-powered skill gap detection,
interactive micro-learning course generation, automated PDF certificate issuance,
tiered payment subscription management, and complete executive administration.

Core Architecture Pillars:
  • Backend Engine     : FastAPI (Python 3.10+) with Async Route Controllers
  • Intelligence Layer : Scikit-Learn (TF-IDF & Cosine Similarity), Groq AI API
  • Storage & Database : SQLAlchemy ORM with SQLite / Supabase Storage Buckets
  • PDF Engine         : ReportLab for instant PDF certificate rendering
  • Frontend Layer     : HTML5, Modern HSL Vanilla CSS, Modern JavaScript ES6
  • Containerization   : Docker & Docker Compose multi-stage runtime environment

  • requests           : Supabase Storage REST API Integration
  • jinja2             : Server-Side HTML Rendering


5. EXTERNAL API KEY SETUP INSTRUCTIONS
--------------------------------------------------------------------------------

To configure API keys, edit or create the `.env` file in the project root:

[A] GROQ AI KEY (For Dynamic Course & Quiz Generation):
  1. Register for a free account at https://console.groq.com/
  2. Navigate to API Keys -> Create New Secret Key.
  3. Add to `.env`:
     GROQ_API_KEY=gsk_your_groq_api_key_here

[B] SUPABASE CLOUD STORAGE BUCKETS (For Cloud Certificate & Resume Storage):
  1. Sign up at https://supabase.com/ and create a new project.
  2. Navigate to Project Settings -> API. Copy Project URL & anon/service role key.
  3. Navigate to Storage -> Create 4 Public Buckets:
     - `images`
     - `videos`
     - `files`
     - `certificates`
  4. Add to `.env`:
     SUPABASE_URL=https://your-project-id.supabase.co
     SUPABASE_KEY=your_supabase_anon_or_service_key

[C] RAZORPAY PAYMENT GATEWAY (Optional Online Card Payments):
  1. Sign up at https://dashboard.razorpay.com/
  2. Navigate to Settings -> API Keys -> Generate Key ID and Key Secret.
  3. Add to `.env`:
     RAZORPAY_KEY_ID=rzp_test_your_key_id
     RAZORPAY_KEY_SECRET=your_key_secret


6. MODULE CONNECTION & FUNCTIONALITY BREAKDOWN
--------------------------------------------------------------------------------

Module 1: Web Server Layer (`main.py`, `app/api/*`)
  - Description: Manages web routes, request validation, Jinja2 template rendering,
    and mounts static assets. Includes API routers for Auth, Courses, Quizzes,
    and Subscriptions.

Module 2: Resume Parser & AI Matcher (`utils/analyzer.py`, `utils/extractor.py`)
  - Description: Extracts text from uploaded resumes using PyPDF/pdfplumber, normalizes
    skill terms via `skill_normalizer.py`, and computes TF-IDF vector similarity
    against target job roles to output match percentage scores and gap lists.

Module 3: AI Micro-Learning Service (`app/services/ai_course_service.py`)
  - Description: Calls Groq AI to generate structured 3-part micro-courses (Introduction,
    Core Methodology, Code Project) and interactive quizzes tailored to missing skills.

Module 4: PDF Certificate Engine (`app/services/certificate_service.py`)
  - Description: Uses ReportLab to generate printable PDF certificates, uploads them to
    the Supabase `certificates` bucket, and saves unique verification UUID codes in DB.

Module 5: Payment & Coupon Gateway (`app/services/payment_service.py`)
  - Description: Processes coupon codes (e.g. `FREE99` for 100% discount), verifies UPI
    UTR transaction numbers, and integrates Razorpay signatures.

Module 6: Database Persistence & Audit Ledger (`app/core/database.py`, `db.py`)
  - Description: Developed using SQLAlchemy ORM (`create_engine`, `sessionmaker`, `declarative_base`).
    Reads `DATABASE_URL` from `.env`. By default, initializes SQLite database (`sqlite:///./local_dev.db`)
    with `check_same_thread: False`. If `DATABASE_URL` points to remote PostgreSQL (Supabase DB), connects via
    connection pooling (`pool_pre_ping=True`). Features automatic exception catching that reverts to `local_dev.db`
    if remote DB is offline. Manages ORM entities: `User`, `Resume`, `Course`, `GeneratedCourse`, `QuizResult`,
    `Certificate`, `Subscription`, `SystemLog`, `UserView`.

Module 7: Admin Panel (`templates/admin/admin.html`)
  - Description: Provides executive visibility over all registered users, subscription
    package details, certificate ledgers, and system audit logs.


7. STEP-BY-STEP SETUP & EXECUTION GUIDE
--------------------------------------------------------------------------------

OPTION A: LOCAL PYTHON SETUP (Powershell / Command Prompt)

  Step 1: Open Terminal in Project Directory:
    cd c:\Users\TruProjects\Documents\test

  Step 2: Create and Activate Python Virtual Environment:
    python -m venv venv
    .\venv\Scripts\Activate.ps1

  Step 3: Install Required Dependencies:
    pip install -r requirements.txt

  Step 4: Configure Environment Variables:
    Ensure `.env` file exists with valid keys (or default fallback keys).

  Step 5: Launch FastAPI Web Server:
    python main.py
    (OR: uvicorn main:app --reload --host 0.00.0.0 --port 8000)

  Step 6: Access Application in Web Browser:
    • Learner Portal : http://localhost:8000
    • Admin Panel    : http://localhost:8000/admin/dashboard
    • API Swagger    : http://localhost:8000/docs


OPTION B: DOCKER CONTAINER SETUP (Recommended for Production / Isolation)

  Step 1: Open Terminal in Project Directory:
    cd c:\Users\TruProjects\Documents\test

  Step 2: Build Container Image:
    docker-compose build

  Step 3: Run Services in Background Mode:
    docker-compose up -d

  Step 4: View Realtime Logs:
    docker-compose logs -f web

  Step 5: Stop Container Services:
    docker-compose down


8. DATABASE ENTITIES SUMMARY
--------------------------------------------------------------------------------
  • User            : Holds email, full_name, hashed_password, role (user/admin)
  • Resume          : Holds uploaded resume text, score %, detected & missing skills
  • Course          : Holds course metadata, video link, module breakdown
  • QuizResult      : Holds score %, total questions, topic, completion date
  • Certificate     : Holds title, score %, cert_uuid, Supabase certificate_url
  • Subscription    : Holds user_email, plan_name, amount paid, payment_status, coupon_code
